# Artifact provenance and redactions

These are execution artifacts from five paired Question's Gambit / Pi-Serini-style
ablation runs. They include excerpts retrieved from the fixed BrowseComp-Plus
corpus; they do not contain a copy of the bulk dataset or index.

Dataset and corpus metadata identify the releases as MIT licensed:

- https://huggingface.co/datasets/Tevatron/browsecomp-plus
- https://huggingface.co/datasets/Tevatron/browsecomp-plus-corpus
- https://github.com/texttron/BrowseComp-Plus

License metadata was checked on October 22, 2026. Source web page URLs remain in
retrieved documents where available. Individual source materials retain their
original attribution; the benchmark's metadata does not change third-party rights.

The public copies redact credentials, API organization identifiers, and the
absolute local workspace path. Local raw artifacts remain unchanged. No generated
clues, feedback results, expansions, or retrieval events are removed on account of
being incorrect. Failed traces are preserved. No gold-answer judge was run.
